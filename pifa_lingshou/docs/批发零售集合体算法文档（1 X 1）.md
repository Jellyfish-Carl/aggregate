# 批发零售集合体算法文档（1 X 1）

# 背景和目标

在前期已搭建的批发侧集合体模型基础上，进一步纳入零售侧套餐选择收益，从而构建一个真正意义上“1进1出”的集合体模型。

## 目标函数

对每个固定候选套餐 $m\in\{F,L,S\}$ 和每个 $\lambda$，独立求解：

$\min J_m^{BR} = (1-\lambda)\sum_{s\in\mathcal S}p_s\ell_{m,s} + \lambda \left[ \eta_m+ \frac{1}{1-\alpha} \sum_{s\in\mathcal S}p_su_{m,s} \right] + \rho^{slack} \sum_{j\in\mathcal J} \left(\xi_{j,m}^{-}+\xi_{j,m}^{+}\right)$

其中：

$\ell_{m,s}=W_{m,s}-R_{m,s}$

目标函数最小化候选套餐 $m$ 下售电公司的期望净损失、净损失 CVaR 和申报带松弛罚金。由于零售套餐参数和客户负荷均为外部输入，$R_{m,s}$ 是给定套餐下的外生收入；优化器通过批发交易、合同和储能决策降低售电公司的净损失风险。

$m$ 是外层候选套餐索引，不属于决策变量。固定 $m$ 后，模型使用该套餐产生的场景零售收入 $R_{m,s}$，独立优化批发合同、日前交易、实时交易和储能策略。三种套餐分别求解，不在同一个 MILP 中通过变量选择套餐。

## 约束

### 1\. 套餐选择与变量范围约束

$0\le X_{r,h,m}^{buy}\le U_{r,h}^{buy}$

$0\le X_{r,h,m}^{sell}\le U_{r,h}^{sell}$

$\underline P_h\le P_{h,m}\le\overline P_h$

$\underline P_h^{ann}\le P_{h,m}^{ann}\le\overline P_h^{ann}$

$\underline C_j\le C_{j,m}\le\overline C_j$

$\underline K\le K_m^C\le\overline K$

$\underline W\le W_{m,s}\le\overline W$

$\underline\ell\le\ell_{m,s}\le\overline\ell$

$\underline\eta\le\eta_m\le\overline\eta$

$0\le u_{m,s}\le\overline\ell-\underline\eta$

前两式对每个客户 $i$、套餐 $m$ 成立，要求每个已确认客户恰好采用一种套餐并声明二进制域；第三式对所有产品 $r$ 和合同点 $h$ 成立，限制新增合同只能在市场允许的成交量范围内发生；第四至第七式对相应的合同、成本和风险辅助变量及其索引成立，给出求解器有限数值边界。这些均为硬约束，数值边界不代表额外业务限制。

### 2\. 三类零售套餐的结算单价约束

定义：

$d_{i,s,j}=P^{ref}_{s,j}-b_i$

固定价套餐：

$\widetilde T_{i,F,s,j}=f_{i,j}$

市场联动套餐：

$\widetilde T_{i,L,s,j}=P^{ref}_{s,j}+g_{i,j}$

比例分成套餐：

$\widetilde T_{i,S,s,j}=b_i +\beta_i^{up}\max(d_{i,s,j},0) -\beta_i^{down}\max(-d_{i,s,j},0)$

统一应用价格边界：

$T_{i,m,s,j} = \min\left( \overline P_{i,m,j}, \max\left(\underline P_{i,m,j},T_{i,m,s,j}^{raw}\right) \right)$

上述四式对所有客户、场景和时段成立。固定电价套餐在不同时段使用 $f_{i,j}$；市场联动套餐为参考价加服务费；比例分成套餐中客户承担 $\beta_i$ 比例的市场涨跌。

### 3\. 零售负荷、客户账单与收入约束

$L_{s,j}=\sum_{i\in\mathcal I}q_{i,s,j},\qquad j>n^{fixed}$

$Bill_{i,m,s} = \sum_{j\in\mathcal J} q_{i,s,j}T_{i,m,s,j}$

$R_{m,s} = \sum_{i\in\mathcal I}Bill_{i,m,s}$

以上等式对未执行时段 $j>n^{fixed}$ 成立；已执行时段的 $L_{s,j}$ 由第 13 项锁定为实际聚合负荷。客户负荷 $q_{i,s,j}$ 在本模型中为入参，不随套餐单价改变；只有另行引入客户需求响应模型后，套餐才会通过负荷直接改变申报与储能的物理可行域。

### 售电公司净利润定义

$\Pi_{m,s} = R_{m,s}-W_{m,s}$

$\ell_{m,s} = W_{m,s}-R_{m,s} = -\Pi_{m,s}$

其中 $\Pi_{m,s}$ 为售电公司利润，$\ell_{m,s}$ 为售电公司净损失。

### 4\. 客户账单可接受性约束

$\sum_{s\in\mathcal S}p_sBill_{i,m,s} \le B_i^{max}$

该约束对每个客户 $i$ 成立，是硬约束。它防止模型仅因售电公司利润最大而选择客户不可接受的高账单套餐。若业务采用“相对外部报价节省率”口径，应先将该口径换算为 $B_i^{max}$。

### 售电公司期望利润下限

$\sum_{s\in\mathcal S}p_s\Pi_{m,s} \ge \Pi^{min}$

等价写为：

$\sum_{s\in\mathcal S}p_s\ell_{m,s} \le-\Pi^{min}$

该约束用于保证候选套餐 $m$ 下售电公司期望利润不低于业务要求。

### 售电公司利润尾部风险上限

$CVaR_{\alpha}(\ell_m) \le L^{profit,max}$

使用线性 CVaR 辅助变量表示为：

$\eta_m+ \frac{1}{1-\alpha} \sum_{s\in\mathcal S}p_su_{m,s} \le L^{profit,max}$

其中：

$u_{m,s}\ge\ell_{m,s}-\eta_m$

$u_{m,s}\ge0$

### 5\. 合同仓位与中长期覆盖约束

$P_{h,m} = C_h^{old} + \sum_{r\in\mathcal R} \left( X_{r,h,m}^{buy} - X_{r,h,m}^{sell} \right)$

$P_{h,m}^{ann}=C_h^{ann,old}+X_{r^{ann},h,m}^{buy}-X_{r^{ann},h,m}^{sell}$

$P_{h,m}^{ann}\ge\phi^{ann}D_{h,m}^{month}$

$\phi^{low}D_{h,m}^{month}\le P_{h,m}\le\phi^{high}D_{h,m}^{month}$

上述约束对每个合同点 $h$ 成立。第一式汇总历史锁定仓位和当前新增交易；第二式单独计算年度产品仓位；第三式和第四式分别执行年度覆盖底线与总体中长期覆盖范围。$ann$ 表示年度产品在 $\mathcal R$ 中的对应索引。这些均为硬约束，日前和实时电量不能用于满足该覆盖要求。

### 6\. 合同曲线映射与合同成本约束

$C_{2h-1,m}=\frac{1}{2}P_{h,m}$

$C_{2h,m}=\frac{1}{2}P_{h,m}$

$K_{m}^C=K_{m}^{old}+\sum_{r\in\mathcal R}\sum_{h\in\mathcal H}(k_{r,h,m}^{buy}X_{r,h,m}^{buy}-k_{r,h,m}^{sell}X_{r,h,m}^{sell})$

前两式将每个半小时合同电量等量拆分至相邻两个 15 分钟点，适用于所有 $h\in\mathcal H$。第三式计算完整交割期合同成本；卖出合同以收入减少成本。合同手续费已包含在 $k_{r,h,m}^{buy}$ 和 $k_{r,h,m}^{sell}$ 中，不能在后续批发成本中重复计入。

### 7\. 日前申报范围与申报带约束

$0\le A_j\le U_j^{phys}$

$A_j+\xi_j^-\ge P10_j$

$A_j-\xi_j^+\le\min(U_j^{phys},P90_j)$

$\xi_j^-\ge0,\qquad \xi_j^+\ge0$

上述约束对每个时段 $j$ 成立。申报量必须位于物理上限内；预测带冲突或越界时由松弛变量保证可行，并按目标函数中的 $\rho^{slack}$ 计罚。除松弛变量外均为硬约束。

### 8\. 合同、日前与实时交易范围及平衡约束

$0\le B_j^{DA}\le U_j^{DA}$

$0\le S_j^{DA}\le U_j^{DA}$

$A_j-B_j^{DA}+S_j^{DA}=C_j$

$0\le B_{s,j}^{RT}\le U_j^{RT}$

$0\le S_{s,j}^{RT}\le U_j^{RT}$

日前交易范围和合同平衡对每个 $j$ 成立；实时交易范围对每个场景 $s$、时段 $j$ 成立。日前买卖与实时买卖在本模型中没有硬互斥二进制约束，正交易摩擦 $\tau$ 仅从经济上抑制同一时段同时买卖；若市场规则要求绝对禁止，应追加交易方向二进制变量和 Big\-M 约束。

### 9\. 储能充放电互斥与 SOC 递推约束

$0\le c_j\le Q^{max}z_j^c$

$0\le d_j\le Q^{max}z_j^d$

$z_j^c+z_j^d\le1$

$z_j^c\in\{0,1\},\qquad z_j^d\in\{0,1\}$

$e_1-\eta^{bat}c_1+\frac{1}{\eta^{bat}}d_1=E^{init}$

$e_j-e_{j-1}-\eta^{bat}c_j+\frac{1}{\eta^{bat}}d_j=0$

$E^{min}\le e_j\le E^{max}$

$e_{96}=E^{init}$

充放电互斥、SOC 上下界和 SOC 递推均为对每个 $j$ 的硬约束；第二个 SOC 递推式仅对 $j=2,\ldots,96$ 成立。终端 SOC 回到初始 SOC，防止模型依靠期末透支获得虚假的储能收益。

### 10\. 场景物理平衡与实时偏差约束

$A_j+B_{s,j}^{RT}-S_{s,j}^{RT}-c_j+d_j=L_{s,j}$

$B_{s,j}^{RT}-S_{s,j}^{RT}-x_{s,j}^{+}\le\delta L_{s,j}$

$S_{s,j}^{RT}-B_{s,j}^{RT}-x_{s,j}^{-}\le\delta L_{s,j}$

$0\le x_{s,j}^{+}\le\bar x_{s,j}^{+}$

$0\le x_{s,j}^{-}\le\bar x_{s,j}^{-}$

以上约束对每个场景 $s$、时段 $j$ 成立。第一式是批零一致的物理能量平衡；其余约束限制实时净偏差在负荷比例 $\delta$ 内。将 $\bar x_{s,j}^{+}$ 和 $\bar x_{s,j}^{-}$ 设为 0 时，偏差限制为硬约束；设置正值时，超限量作为受罚松弛。

### 11\. 场景批发成本与净损失定义约束

$W_{m,s} = K_m^C + \sum_{j\in\mathcal J} \left[ (DA_{s,j}+\tau)B_{j,m}^{DA} - (DA_{s,j}-\tau)S_{j,m}^{DA} \right.$$\left. + (RT_{s,j}+\tau)B_{m,s,j}^{RT} - (RT_{s,j}-\tau)S_{m,s,j}^{RT} + \rho_{s,j}^{dev,+}x_{m,s,j}^{+} + \rho_{s,j}^{dev,-}x_{m,s,j}^{-} + \rho^{deg}(c_{j,m}+d_{j,m}) \right]$

净损失定义为：

$\ell_{m,s} = W_{m,s}-R_{m,s}$

利润定义为：

$\Pi_{m,s} = R_{m,s}-W_{m,s}$

上述等式对每个场景 $s$ 成立。$W_s$ 统一计入合同、日前、实时、偏差、交易摩擦和储能退化成本；$\ell_s$ 是售电组合风险度量的唯一场景损失口径。申报带松弛罚金已在目标函数中单独计入，不能再次写入 $W_s$。

### 12\. CVaR 风险约束

$u_{m,s}\ge\ell_{m,s}-\eta_m$

$u_{m,s}\ge0$

两式对每个场景 $s$ 成立。$\eta$ 为 VaR 辅助变量，$u_s$ 为超额净损失；它们与目标函数共同形成置信度 $\alpha$ 的净损失 CVaR。该风险约束将固定价套餐的价格暴露、联动套餐的收入对冲、比例分成套餐的部分风险转移与批发合同、申报和储能风险放在同一评价口径中。

### 13\. 已锁定套餐、申报与实时执行前缀约束

$A_{j,m}=\bar A_j$

$B_{m,s,j}^{RT}=\bar B_j^{RT}$

$S_{m,s,j}^{RT}=\bar S_j^{RT}$

$c_{j,m}=\bar c_j$

$d_{j,m}=\bar d_j$

$e_{j,m}=\bar e_j$

$L_{s,j}=\bar L_j^{actual}$

第一式仅对 $i\in\mathcal I^{lock}$ 的已签约客户及所有套餐 $m$ 成立；第二式仅对 $j\in\mathcal J^{DA,lock}$ 成立；第三、第四式仅对 $j\le n^{fixed}$ 的已执行实时前缀、所有场景 $s$ 成立；第五式仅对 $j\le n^{fixed}$ 成立。它们都是硬锁定约束，确保滚动求解只能修改尚未承诺或执行的未来决策；已执行前缀使用实际负荷而不是预测负荷。

|客户|$F$|$L$|$S$|
|---|---|---|---|
|$i_1$|1|0|0|
|$i_2$|1|0|0|
|$\cdots$|1|0|0|
|方案 $F$|1|0|0|

|客户|$F$|$L$|$S$|
|---|---|---|---|
|$i_1$|0|1|0|
|$i_2$|0|1|0|
|$\cdots$|0|1|0|
|方案 $L$|0|1|0|

|客户|$F$|$L$|$S$|
|---|---|---|---|
|$i_1$|0|0|1|
|$i_2$|0|0|1|
|$\cdots$|0|0|1|
|方案 $S$|0|0|1|

其中行对应客户，列对应套餐 $F,L,S$。

如果客户已有不同套餐归属，则输入外部矩阵 $\bar y_{i,m}^{(k)}\in\{0,1\}$，并满足 $\sum_{m\in\mathcal M}\bar y_{i,m}^{(k)}=1$。

此时总账单为 $Bill_{i,s}^{(k)}=\sum_{m\in\mathcal M}\bar y_{i,m}^{(k)}Bill_{i,m,s}$，总零售收入为 $R_s^{(k)}=\sum_{i\in\mathcal I}Bill_{i,s}^{(k)}$。

|客户|固定套餐 $F$|联动套餐 $L$|分成套餐 $S$|选定方案|
|---|---|---|---|---|
|$i_1$|0/1|0/1|0/1|$F/L/S$|
|$i_2$|0/1|0/1|0/1|$F/L/S$|
|$\cdots$|||||

当前阶段“选定方案”不是模型自动决策结果，而是外部输入或方案筛选结果。只有未来重新引入 $y_{i,m}$ 决策变量后，才可以称为“优化得到的套餐选择矩阵”。

## 5\. 风险收益曲线

对每个套餐 $m$，随着 $\lambda$ 变化绘制以下曲线：$\lambda$ 与 $E[\Pi_m]$，$\lambda$ 与 $CVaR_\alpha(-\Pi_m)$，以及 $\lambda$ 与 $E[W_m]$。

建议使用以下综合图：

- 横轴：$CVaR_\alpha(-\Pi_m)$；

- 纵轴：$E[\Pi_m]$；

- 颜色：候选套餐 $F,L,S$；

- 点型或标签：不同的 $\lambda$。

该图用于展示不同风险偏好下的成本、利润和尾部风险之间的权衡。

需要注意：不同 $\lambda$ 下的结果不是同一个固定策略的统计区间，而是不同风险偏好下重新优化得到的策略结果。P10\-P90 区间描述场景不确定性，$\lambda$ 曲线描述策略变化，二者含义不同。

## 6\. 最终方案筛选规则

候选方案 $(m,\lambda)$ 应至少满足以下条件：$E[Bill_{i,m}]\le B_i^{max}$（对所有客户 $i$），$E[\Pi_m]\ge\Pi^{min}$，以及 $CVaR_\alpha(-\Pi_m)\le L^{profit,max}$。

在满足约束的候选方案中，可以按以下顺序筛选：

1. 优先剔除任一客户期望账单超过 $B_i^{max}$ 的方案；

2. 剔除售电公司期望利润低于 $\Pi^{min}$ 的方案；

3. 剔除利润 CVaR 超过 $L^{profit,max}$ 的方案；

4. 在剩余方案中比较 $E[\Pi_m]$、客户期望节省额和利润区间；

5. 如果存在多个不可支配方案，向业务方展示 Pareto 前沿，而不是强行使用单一最优方案。

最终结果应同时包含：

- 选中的套餐方案 $m$；

- 风险权重 $\lambda$；

- 售电公司期望成本；

- 售电公司期望收入；

- 售电公司期望利润；

- 利润 P10\-P90；

- 利润 CVaR；

- 每个客户的账单期望和 P10\-P90；

- 每个客户的节省额期望和 P10\-P90；

- 套餐选择矩阵；

- 约束是否满足及违反程度。
